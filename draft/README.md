# draft-rsdggs-informational-00

`draft-rsdggs-informational-00.xml` is the xml2rfc v3 source of the Internet-Draft. Render it with [xml2rfc](https://pypi.org/project/xml2rfc/):

```sh
pip install xml2rfc
xml2rfc --text --html draft/draft-rsdggs-informational-00.xml
```

The first commit of this file is the export from the drafting chat session of 2026-06-15, unmodified. That export has **no tables and no lists**: the docx draft has 22 tables and 43 numbered or bulleted items that are missing here (for example §5.2, §9.x, §14.2 and §20, and the procedures in §11.2, §11.3, §12, §14.4 and §17.5). The §5.2 table has since been restored with the 4-bit triangle selector change. The rest still need restoring from the docx.
